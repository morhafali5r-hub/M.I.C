الدليل الاستخباراتي للنظام

[SYS_01]: تغليف الصور

إخفاء أي نص سري أو ملف ضخم داخل بكسلات صورة الغطاء بصيغة (PNG/JPG). يجب حفظ الناتج بصيغة PNG حصراً لضمان عدم ضياع التشفير. عند فك التشفير، ستتولد "بطاقة استخبارات المطلوبين" تحمل بيانات الملف المخفي.

[SYS_02]: الإخفاء الصوتي

ارفع أي ملف صوتي بأي صيغة وسيقوم النظام بتحويله تلقائياً لصيغة WAV النقية. سيتم بعد ذلك حقن النصوص أو الملفات داخل الترددات الصغرى للصوت. النتيجة: ملف صوتي يعمل بشكل طبيعي، ولا يمكن لأي أذن بشرية تمييز التشفير بداخله.

[SYS_03]: محطة راديو مورس

ترجمة النصوص إلى ذبذبات مورس الكلاسيكية مع خيار بثها صوتياً أو تحميلها كملف WAV.
المحطة قادرة أيضاً على قراءة ملفات الصوت المرفوعة وتحليل موجاتها لاستخراج نبضات مورس منها تلقائياً وفك شفرتها. تأكد من تحديد لغة الشفرة الصحيحة لتفادي تداخل الحروف.

[SYS_04]: الإتلاف الجذري للمصفوفات

نظام تحكم كامل في بنية الملفات الفيزيائية عبر التلاعب بالبايتات:

  • إتلاف (CORRUPT): تمزيق وتشفير بنية الملف ليصبح غير قابل للتشغيل، لا يمكن استعادته إلا بنفس كلمة السر أو مفتاح الأمان المرفق.
  • استرجاع (RESTORE): فك التشفير عن الملف المتلف مسبقاً لإعادته إلى حالته الطبيعية والعمل بكفاءة.

[SYS_01]: IMG STEGO

Hide any secret text or heavy file inside the pixels of a Cover Image (PNG/JPG). You MUST export the result as PNG format to prevent data loss. Decryption generates a cinematic Wanted Intelligence Dossier.

[SYS_02]: AUDIO STEGO

Upload ANY audio format. The core auto-converts it to pure WAV format, then injects text or files into the Least Significant Bits (LSB) of the audio frequencies. The resulting audio plays normally, perfectly inaudible to human ears.

[SYS_03]: RADIO MORSE

Translate text to classic Morse pulses with the ability to broadcast acoustically or download as a WAV file. It can also analyze uploaded audio waves to extract and decode Morse pulses automatically. Ensure the Language Dictionary is set correctly to avoid pulse collisions.

[SYS_04]: ABSOLUTE KILL MATRIX

Total physical byte control using Matrix manipulations:

  • CORRUPT: Scrambles file bytes physically. Can only be restored with the exact password or physical key.
  • RESTORE: Unlocks a previously corrupted file back to its fully working original state.
